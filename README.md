# Crimson Keep

A 2D top-down gothic roguelite built entirely in code: no image, model or audio files. Every sprite, tile, icon and card is drawn from vector primitives, and every sound and music note is synthesized at runtime.

It is built from the *Code-Only 2D Top-Down Roguelite* build spec. The spec's neon look is replaced with a **chunky-cartoon × Castlevania** art direction:

- **Chunky cartoon** (from the reference screenshot): thick ink outlines, flat saturated fills with a single cel highlight, chibi heroes with big eyes, pill-shaped HUD bars (EXP badge, heart HP pill, sword and shield stats, gem counter) and lavender ability tiles.
- **Gothic castle** (Castlevania): brick-faced castle halls with red carpet runners, flickering torches and candelabras, stained-glass windows throwing moonbeams, cobwebs, coffins and bones. Enemies include bats, skeletons, ghouls, axe armors and gargoyles. The bosses are a two-headed ogre, a rune-carved stone golem and a vampire count. Holy cross, axe and holy water sub-weapons are upgrade cards, and the music is procedural harpsichord and organ.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # generation, simulation and performance tests (vitest)
npm run build      # typecheck + production build into dist/ (installable PWA)
npm run preview    # serve the production build
```

Useful URL parameters: `?quality=ultra|high|medium|low`, `?autostart=vanguard|weaver|phantom&seed=ABC123` (skips the title), and `?debug=1` (exposes `window.__ck`).

## Controls

| Action | Keyboard + Mouse | Gamepad | Touch |
|---|---|---|---|
| Move | WASD / arrows | Left stick | Floating left joystick |
| Aim / attack | Mouse + hold LMB | Right stick (auto-fires) / RT | Floating right joystick (auto-fires) |
| Class ability | Space / RMB | A | Ability button |
| Dash | Shift | B | Dash button or swipe |
| Interact | E | X | Contextual hand button |
| Pause / Map | Esc / Tab or M | Start / Select | Gear icon / tap the minimap |

The active input method switches live on the first event from any device. Every menu works with mouse, touch, keyboard (arrows + Enter) and gamepad (D-pad + A/B).

## What's in the game

- **3 floors**, each a branching node graph (Battle, Elite, Mystery, Shop, Sanctuary, Boss) with a new layout every floor and every retry. Any run is reproducible from its seed.
- **Rooms** are generated with BSP partitioning, A\* corridors (with a turn penalty so corridors and carpets run straight), cellular-automata caverns, flood-fill connectivity validation and Poisson-disc spawns. Tests check that every room is fully connected.
- **3 classes**: Vector Vanguard (arc slash and Shockwave Dash), Code Weaver (homing orbs and Singularity Pulse) and Phantom Blade (twin daggers and Shadow Step).
- **RPG loop**: XP and levels, +3 stat points per level (STR/AGI/VIT/INT/FOC, with caps), 27 data-driven upgrade cards with rarity, tier and tag synergies, 21 items across 4 equipment slots with forge upgrades, a shop, mystery events, chests and blood shrines.
- **Meta-progression**: gems convert to souls at the end of a run. Souls unlock classes, card packs and starting stat bonuses. Saved in IndexedDB, plus a mid-run save offered as "Continue Run".
- **Bosses**: Gorehorn (slam shockwaves, charges, rockfall, summons), the Rune Colossus (rune bursts, ground spikes, spirals) and Count Vlador (teleports, hellfire, blood spirals, bat swarms).

## Architecture

```
src/
  config.ts  theme.ts      all tunables / palette tokens + per-floor castle themes
  core/                    fixed 120 Hz loop, sfc32 RNG + hashCombine, SoA slot pools, spatial hash
  gen/                     graph, BSP, A*, cellular automata, Poisson disc, room assembly, spawner, loot
  game/                    World simulation (headless), enemy AI + bosses, player combat, cards, items, stats, meta
  render/                  PixiJS v8 renderer, shared GraphicsContext shape cache, art/, particles, room view, perf
  platform/                device profile, unified input (pointer, keyboard, gamepad, virtual sticks), settings
  ui/                      DOM HUD + screens (cartoon-gothic CSS), SVG icon set, spatial focus navigation
  audio/                   vendored ZzFX synth, SFX mixer (8 voices, 30 ms merge), procedural music
  save/                    IndexedDB key-value wrapper
build/appIcon.ts           code-drawn PWA icon (manifest + offline service worker generated by vite.config.ts)
```

- The simulation (`game/`) has no rendering imports. It emits effects through an `FxSink`, so it runs headless in tests.
- Enemies, projectiles, pickups, hazards and particles are structure-of-arrays typed-array pools. Every shape is built once as a `GraphicsContext` and shared by all instances.
- Rendering interpolates between simulation ticks and draws the additive glow layer through a `ParticleContainer`. Ultra adds a blurred bloom pass. Dynamic resolution scaling drops the render scale 0.1 at a time (floor 0.5) when frames run over budget, and a thermal step-down lowers the preset after sustained slowdowns.
- The bundle is about 250 KB gzipped. A heavy 140-enemy combat tick takes about 0.3 ms in Node (the spec budget is 2–4 ms).

## Deviations from the spec

- **HUD is DOM, not a Pixi container.** It stays sharp at any render scale and uses CSS `env(safe-area-inset-*)` directly. Menus are DOM too, which gives touch, focus navigation and accessibility for free.
- **Actors are y-sorted** on one layer (player and enemies interleave by depth) instead of strictly "enemies then player". That reads correctly in the 3/4 castle view.
- **PWA icons are SVG.** Android and desktop install fine. iOS home-screen icons prefer PNG, which would need a rasterization step at build time.
- **Zero-allocation hot loop** holds for the simulation. A few presentation paths still allocate small objects: WebAudio nodes per sound or note, damage-number text updates, and room loading.
- **Testing so far is automated only:** unit, simulation and performance tests, plus headless-Chromium playthroughs on desktop and an emulated Pixel 7 (touch). The full real-device test matrix (iPhone, iPad, Android tablet, 4K/120 Hz, physical controllers) and the optional Capacitor or Tauri wrappers have not been done.
